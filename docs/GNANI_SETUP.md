# Gnani setup status

Live Prisma (STT) and Timbre (TTS) adapters are not yet implemented. The UI marks voice as unconfigured and disables microphone input. Do not set expectations of a live voice demo until the official Gnani request/response contracts have been checked against current provider documentation, implemented server-side, and tested with valid credentials. `.env.example` reserves server-only configuration names; no credentials belong in browser variables or Git.
