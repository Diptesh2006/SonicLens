# Sonification mapping

Only a user click starts sound. For the selected metric, trend observations map linearly from the selected series minimum–maximum to 180–940 Hz. The value sequence determines event order; anomaly mode selects robust outliers and abrupt changes (falling back to the maximum if none are detected) and uses triangle waves, while trend uses sine waves. Comparison mode plays aligned pairs from both periods and maps each signed difference to 560 Hz at zero, with the largest absolute difference in that analysis spanning 180–940 Hz; comparison notes use triangle waves. The normalized comparison scale preserves direction and relative magnitude for that result. Long previews select at most 150 evenly spaced indices from the already-selected plan; this is audio preview downsampling and does not alter analysis or evidence. Each tone is enveloped to 150 ms; playback rate changes spacing, zero volume skips tone generation, and the chart cursor follows the exact scheduled observation index. Starting spoken playback stops the sonification player so narration and notes do not overlap. This is an exploratory mapping, not a claim that sound improves analysis.
